## 🚀 How @arog Uses This

### Before Every Response
```bash
1. Read RULES.md (10 mandatory rules)
2. Check KNOWN-ISSUES.md (avoid active problems)
3. Review SESSION-LOG.md (last 5 interactions)
4. Search ISSUES-FIXES-BANK.md (similar past issues)
```

### During Work
```bash
1. Follow PROCESS.md for standard procedures
2. Refer to GUIDELINES.md for detailed instructions
3. Log actions in SESSION-LOG.md in real-time
4. Update KNOWN-ISSUES.md if issues found
```

### After Work
```bash
1. Update SESSION-LOG.md with results
2. Update ISSUES-FIXES-BANK.md if fixing bugs
3. Run validation tests
4. Mark issues resolved
```
